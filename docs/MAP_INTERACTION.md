# 地图交互

地图只显示游戏图标，不显示点位名称、建筑类型或首领描述，也不用汉字代替图标。具体名称和内容放在点击后的详情里；位置方位默认折叠。

建筑类型与首领身份分别判断：候选全部为遗迹，即使敌人不同，也显示遗迹图标。营地、遗迹等类型不一致时保留中性点位。野外首领的红／白图标来自具体档案的参数记录；不能从首领名字猜颜色。神授塔保持一塔一个图标，点击查看三层。

| 状态 | 图标 | 点击 |
| --- | --- | --- |
| 全图，地图边长小于 800 像素 | 手机 24、桌面 28 像素 | 密集处放大到目标附近 |
| 区域，地图边长至少 800 像素 | 手机 44、桌面 36 像素 | 点击点位查看或标记 |
| 继续放大 | 保留图标，不增加文字 | 已确定点位直接查看详情 |

所有点位独立保留，避让不改变真实坐标，不形成数量聚合。点击放大不生成筛选条件，可返回原视野。键盘明确选中点位时直接打开。建筑快捷标记采用图标按钮；无关候选不出现。夜王、特殊地形、出生点与 DLC 地表／地下筛选保留。

自动放大开关保存在当前标签页。旧版文字显示偏好不再恢复。界面不展示这份文档中的实现说明。

## 来源与验证

游戏图标、原始文件哈希及红／白首领对应关系见 [第三方说明](../THIRD_PARTY.md)。

- [官方入门指南](https://media-center.bandainamcoent.eu/games/elden-ring-nightreign/ERN_FuturePress_StarterGuide.pdf)：游戏地图图标。
- [W3C 点击目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)：点击尺寸与间距。
- [NN/g 渐进披露](https://www.nngroup.com/articles/progressive-disclosure/)：按需呈现详情。

`tests/icons-browser.py` 覆盖真实资源加载、类型确定但首领未定、红／白首领、缩放不出现文字、旧偏好迁移、手机与桌面。`tests/map-zoom-browser.py` 覆盖五种屏幕、六档缩放、防重叠、密集点选和返回。算法测试与 DLC、三层神授塔、筛选、无障碍回归继续执行。

## 底图加载

页面初始化即请求目标地形的总览和切片，不等待档案数据。先展示总览，36 张切片解码完成后整体替换，保持视角。切换目标图尚未准备好时保留上一张画面并暂停点位操作，避免旧底图配新点位；旧请求完成后不能覆盖新选择。等待提示延迟 250 毫秒，快速缓存切换不闪提示。高清失败时保留可操作总览和重试入口。

总览在空闲时按低优先级逐张预载；省流量和 2G 连接跳过其他地形。只保留最近两张已解码高清地图，不批量预载所有高清切片。旧文字显示偏好和图标交互规则不变。
