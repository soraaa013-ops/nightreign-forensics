# 地图性能记录

对比基线为 `860fecb`，使用 Chromium、390×844 视口、CPU 四倍降速、关闭缓存。两版均由本地 Python HTTP 服务提供，不启用 HTTP 压缩。以下是单次受控回归数据，不代表用户实际网络耗时。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 常规网络首次点位可操作 | 2199 ms | 1138 ms |
| 常规网络高清图就绪 | 2230 ms | 1161 ms |
| 常规网络筛选更新 | 168 ms | 110 ms |
| 慢网首次点位可操作 | 27226 ms | 5276 ms |
| 慢网高清图就绪 | 27241 ms | 7180 ms |

慢网配置：100 ms 延迟、下载 250000 B/s、上传 125000 B/s。

运行时档案将重复点位与图标去重，从三个合计约 5.2 MB 的 JSON 合并为约 655 KB，自动测试逐项还原比对全部 520 份档案。每张高清地图从 36 个请求降为 1 个；24 个界面图标合计约 168 KB。先加载总览与数据，再加载高清图；筛选复用图标节点，拖动和缩放按动画帧绘制。

复测：启动服务后运行 `TEST_BASE_URL=http://localhost:4173 python3 tests/map-performance.py`，加 `SLOW=1` 测慢网。脚本需要 Playwright；比较旧版本时加 `ALLOW_LEGACY=1`。自动检查单张高清图、图标节点复用以及不请求旧版大数据文件。
