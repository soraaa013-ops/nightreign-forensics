# 体验优化与验证

验证日期：2026-11-18。修改保留遗物检测、精确概率、报告链接和地图反查功能，未更换原始快照或算法。

## 体验调整

- 深蓝与旧金色界面；桌面并排显示录入区与报告，手机为单列。
- 遗物用独立词条库选择，已选内容显示全文，编号仅在同名词条需要区分时显示。角色与效果类型可交叉筛选，支持空格分隔关键词和“回血”“回蓝”“大招”等别名。
- 默认显示当前模板可用词条；模板外词条通过显式开关查看，仍可检测非法组合。重复和互斥词条在选择前提示。
- 选齐三条自动检测；支持替换、移除、上下移动和一键按游戏顺序排列。移除后报告与分享状态立即失效。
- 地图先搜索敌人或据点，地点类型和位置可选。未知位置时，线索表示该地图任意符合类型的地点存在此内容；多条线索取交集。
- 每个选项显示应用后的候选数量；零候选项禁用，已选条件可逐条撤销。观察数量不限，支持候选预览、推荐位置和完整地点详情。
- 手机端默认折叠夜王、地形、出生点和位置条件。保留加载重试、复制失败手动复制、键盘操作和减少动态效果支持。

## 中文范围与来源

`data/zh-CN.json` 覆盖现有数据包的 896 条效果、1305 个遗物模板，以及 320 份地图档案中所有显示字段，包括夜王、特异地形、地点、敌人、事件、夜晚安全区、魔法师塔谜题和推荐位置。源数据中的英文键、编号、来源记录保持原样，仅展示文本中文化。

遗物文本以原快照已有的繁体中文为基础，经 OpenCC 的 `t2s` 转为简体；全角血量与专注值缩写改为中文，“绝活”统一为简中“绝招”。地图地点中“亚历山大所在处”“骑兵桥东侧”等是原档案的定位描述，不宣称为游戏内正式地名。

查证入口：

- [资料站三语菜单文本](https://wiki.biligame.com/nightreign/三语:所有菜单文本)：夜王与特异地形名称；采用格拉狄乌斯、格诺斯塔、布德奇冥等游戏文本用名。
- [资料站野外头目总览](https://wiki.biligame.com/nightreign/野外头目总览)：核对卡利亚禁卫骑士、石肤众王、混种集团、魔像守卫等。
- [Beastly Brigade 对应敌人](https://nightfarerledger.com/codex/bosses/beastly-brigade)：核实其为混种组合，结合中文头目目录采用“混种集团”。
- [全夜王对应夜晚首领整理](https://www.gamersky.com/handbook/202506/1936482.shtml)：交叉核对夜晚首领组合；部分夜王译名与游戏文本不同，以三语文本为准。

更新原始数据后必须补充词库并运行测试；缺译项会让覆盖测试失败。繁简转换不等于重新取得官方简中资源，本次未声称获得新的游戏导出。

## 复现

先安装测试依赖（建议使用自己的 Python 虚拟环境）：

```bash
python3 -m pip install -r tests/requirements.txt
python3 -m playwright install chromium firefox
npm test
npm run test:chinese
npm run validate:data
npm run serve
```

保持服务运行，在另一个终端执行：

```bash
npm run test:browser
TEST_BROWSER=firefox TEST_ARTIFACTS=/tmp/nightreign-qa-firefox npm run test:browser
curl -fsSL https://cdnjs.cloudflare.com/ajax/libs/axe-core/4.10.3/axe.min.js -o /tmp/nightreign-axe.js
AXE_CORE_PATH=/tmp/nightreign-axe.js npm run test:a11y
```

默认服务地址为 `http://localhost:4173`，可通过 `TEST_BASE_URL` 覆盖。截图和扫描结果默认写入 `/tmp/nightreign-qa-artifacts`，可通过 `TEST_ARTIFACTS` 指定持久目录。浏览器测试中的剪贴板成功/拒绝由注入模拟，以稳定覆盖两个分支；规则运算和地图筛选使用真实数据。
