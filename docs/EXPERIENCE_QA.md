# 体验验证记录

## 本次行为

地图默认直接显示独立点位，不聚合、不需要先展开数字点。鼠标与触屏点击吸附最近位置，保留拖动、缩放、图层和键盘操作。选定出生点后隐藏其他出生点；候选中不可能出现的点位与选项不显示。已确定点位点击打开描述，只有主动点击“修改这处信息”才进入编辑。粗略标记与档案推断分开显示。

手机首屏以地图为主，筛选和档案分别按需打开。常用建筑类型直接选择，成功标记后收起面板并保持视角。保留冲突纠错、撤销、分享、草稿与文字检索。遗物检测功能和原始规则快照保持不变。

地图由 320 份本体档案扩展到 520 份，新增 200 份扩展布局，其中大空洞 80 份；安定者们、废弃物之王各 60 份布局。大空洞有独立出生点、据点、关联敌人与地表／地下底图。

## 验证

- Node：54 项算法、中文覆盖、原始快照、点位、筛选及扩展数据检查。
- 通用浏览器回归：遗物与地图共 13 组流程，涵盖分享、撤销、故障重试、存储禁用及响应式页面。
- 地图专项：Chromium 9 组、Firefox 8 组；前者额外执行真实触屏双指缩放。包括不聚合、出生点排除、确定点位详情、320×568 短屏和连续操作。
- 扩展专项：两名新夜王、布局计数、地表／地下切换、真实底图加载、手机点选、完整筛选分享与确定点位描述。
- axe：遗物与地图初始／活动状态、筛选与结果面板共 6 个状态。
- 简体检查：显示词库、页面文字、辅助标签；禁止繁体字和残留血量／专注值英文缩写。
- 规则包验证：零错误、零警告。

扩展数据检查验证全部 200 份记录保留自身线索、可分享恢复、无重复编号、点位坐标有界、全部字段有中文名称、两层各 36 张底图完整。缺少某处数据的记录不会被误认为“已确定为空”；推荐算法不会因地形缺少点位而高估其信息量。

运行方式：

```bash
npm test
npm run validate:data
python3 tests/simplified.py
python3 tests/browser.py
python3 tests/atlas-browser.py
python3 tests/dlc-browser.py
TEST_BROWSER=firefox python3 tests/browser.py
TEST_BROWSER=firefox python3 tests/atlas-browser.py
TEST_BROWSER=firefox python3 tests/dlc-browser.py
AXE_CORE_PATH=/path/to/axe.min.js python3 tests/accessibility.py
```

浏览器脚本需要 Playwright 与对应浏览器，简体检查需要 OpenCC。部署后通过 `TEST_BASE_URL` 指向线上地址复测。

手机筛选新增紧凑布局：夜王、特殊地形、出生点和搜索直接展示；固定底部操作、条件／显示切换、结果页直接返回筛选。验证 320×568、390×844、768×900 的首屏操作以及 390×360 小视口、连续搜索、撤销清空、分享回退与配置切换。命令：`python3 tests/compact-filter-browser.py`。产品文案偏好记录在项目 `AGENTS.md`。

内容优先专项：地图标签、点位标题及档案列表展示建筑、敌人和首领。位置、方位、出生位置与缩圈资料默认折叠；明确展开后可读，指定位置筛选保留。Chromium／Firefox 验证与档案展开状态 axe 检查：`python3 tests/content-priority-browser.py`。

首领标签回归：未确定、仅确定建筑类型、空点、小型据点及属性线索都不生成地图文字；首领确定后去掉建筑前缀。神授塔按楼层判断确定性。覆盖五种屏幕、六档缩放、点选及筛选恢复。

地图图标更新：类型由游戏图标表达，所有缩放等级不显示文字标签；建筑快捷选择也使用图标。红／白首领按档案参数区分，未确定类型不猜测。具体名称在点击详情中保留。新增 `npm run test:icons`，Chromium／Firefox 覆盖图标资源、类型推断、旧偏好迁移、手机／桌面和红白首领；历史“首领确定后显示地图文字”规则已替换。

底图加载专项：`python3 tests/map-preload-browser.py` 使用受控网络延迟，验证档案未返回时先显示总览、高清未完成时仍可点选、地表／地下预载、旧请求不覆盖新地图、缓存复用、分享地形直接预载、省流量模式及总览失败回退。Chromium／Firefox 均执行。原有底图失败重试与多屏幕点选测试继续保留。`tests/map-tiles.test.js` 验证解码完成后再展示、请求去重、两张高清地图的缓存上限、失败重试和总览体积上限。

确定首领标签：更新为游戏类型图标＋具体首领名字，普通教堂＋魔像的类型和名字分别处理。仅确定类型不显示名字。`npm run test:labels` 验证实际点选确认黑刀刺客、教堂魔像、撤销、类型筛选、确定性推断及手机／桌面防重叠；确认后标签无空间时自动放大。此规则替代此前“所有缩放等级均不显示文字”。

连续填写专项：`npm run test:flow` 在 Chromium／Firefox 的 320×568、390×844 触屏及桌面鼠标上验证精确点击不放大、类型后直接展示首领、关闭跳过、同条条件细化、撤销恢复、重载和键盘连续选择。地图回归同时检查邻近吸附放大、拖动与双指手势不误触，以及新面板不被同一次触摸误提交。

性能回归验证：520 份运行时档案与原始数据逐项一致；地图高清资源改为单图，图标复用，拖动每帧合并绘制。Chromium／Firefox 的预加载与连续选择流程通过；地图、缩放、DLC、图标、确认名称及通用页面回归通过。性能结果见 [性能记录](PERFORMANCE.md)。
