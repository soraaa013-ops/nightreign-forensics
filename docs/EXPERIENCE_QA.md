# 体验验证记录

## 本次行为

地图默认直接显示独立点位，不聚合、不需要先展开数字点。鼠标与触屏点击吸附最近位置，保留拖动、缩放、图层和键盘操作。选定出生点后隐藏其他出生点；候选中不可能出现的点位与选项不显示。已确定点位点击打开描述，只有主动点击“修改这处信息”才进入编辑。粗略标记与档案推断分开显示。

手机首屏以地图为主，筛选和档案分别按需打开。常用建筑类型直接选择，成功标记后收起面板并保持视角。保留冲突纠错、撤销、分享、草稿与文字检索。遗物检测功能和原始规则快照保持不变。

地图由 320 份本体档案扩展到 520 份，新增 200 份扩展布局，其中大空洞 80 份；安定者们、废弃物之王各 60 份布局。大空洞有独立出生点、据点、关联敌人与地表／地下底图。

## 验证

- Node：43 项算法、中文覆盖、原始快照、点位、筛选及扩展数据检查。
- 通用浏览器回归：遗物与地图共 13 组流程，涵盖分享、撤销、故障重试、存储禁用及响应式页面。
- 地图专项：Chromium 9 组、Firefox 8 组；前者额外执行真实触屏双指缩放。包括不聚合、出生点排除、确定点位详情、320×568 短屏和连续操作。
- 扩展专项：两名新夜王、布局计数、地表／地下切换、真实底图加载、手机点选、完整筛选分享与确定点位描述。
- axe：遗物与地图初始／活动状态、筛选与结果面板共 6 个状态。
- 简体检查：显示词库、页面文字、辅助标签；禁止繁体字和残留血量／专注值英文缩写。
- 规则包验证：零错误、零警告。

扩展数据检查验证全部 200 份记录保留自身线索、可分享恢复、无重复编号、点位坐标有界、全部字段有中文名称、两层各 36 张底图完整。缺少某处数据的记录不会被误认为“已确定为空”；推荐算法不会因地形缺少点位而高估其信息量。

运行方式：

```bash
npm test
npm run validate:data
python3 tests/simplified.py
python3 tests/browser.py
python3 tests/atlas-browser.py
python3 tests/dlc-browser.py
TEST_BROWSER=firefox python3 tests/browser.py
TEST_BROWSER=firefox python3 tests/atlas-browser.py
TEST_BROWSER=firefox python3 tests/dlc-browser.py
AXE_CORE_PATH=/path/to/axe.min.js python3 tests/accessibility.py
```

浏览器脚本需要 Playwright 与对应浏览器，简体检查需要 OpenCC。部署后通过 `TEST_BASE_URL` 指向线上地址复测。
